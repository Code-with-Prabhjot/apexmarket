# ApexMarket Mission Control Demo Assets

This directory contains visual media and preview assets for the ApexMarket Mission Control interface.

## Video Demonstration
The three-minute narrated product tour video (`apexmarket-mission-control.mp4`) is excluded from Git repository tracking to prevent repository bloat.

To access or download the demonstration video:
- **GitHub Releases:** Download `apexmarket-mission-control.mp4` attached to the latest repository release tag.
- **External Video Hosting / CDN:** Refer to the project portal or artifact repository for streaming mirrors.
- **Local Generation:** To regenerate the demo video locally from recorded state snapshots, run `npm run demo --prefix frontend` (requires `ffmpeg` and Chrome/Puppeteer).

## Included Assets
- `apexmarket-mission-control.srt`: Synchronized subtitle / caption transcript for the video walkthrough.
- `preview.png`: Dashboard preview image.
